# BetterAutoRun
No more pinkie pain!
Player automatically follows path/road on autorun
and avoids obstacles in the wilderness.
So you have your hands free for some rp-chat or just enjoying the beautiful environment.

## Features
- walk or run along a path automatically
- toggle autosprint during autorun (press L-SHIFT once)
- ride along a path automatically
- walk or run over bridges
- autorun through wilderness
- water detection
- avoid lava
- avoid tar pits
- hit prevention
- de-/inclination detection
- path detection
- stuck detection
- evade jump
- correct direction pressing right mouse button

## Dependencies
- BepInExPack for Valheim

## Mod managers
This Thunderstore package is compatible with Gale, Thunderstore Mod Manager, and r2modman.

## Manual Installation
- Extract the content of the `plugins` directory into your `BepInEx/plugins` directory.
